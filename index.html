(Process)

Six steps, each feeding the next.

01/ 06

  1. 01Step

    Business requirements

    Establish what the product must achieve and the constraints it has to respect.

    • Project scope
    • Priorities
    • Constraints
    • ManaGEMScope, priorities and timeline were set with the GEMIS manager.

  2. 02Step

    User needs

    Understand who uses the product, what they are trying to do and where it fails them.

    • Findings
    • Problem statement
    • Design principles
    • ManaGEMPhone conversations with existing clients shaped the dashboard and navigation.

  3. 03Step

    Information architecture

    Organise content and functions so people can predict where things are.

    • Sitemap
    • Navigation structure
    • Page hierarchy
    • ManaGEMExpanding menus became labelled navigation groups.
    • GEMIS

  4. 04Step

    User flows

    Map each task from start to finish, including what happens when something goes wrong.

    • User journeys
    • Task flows
    • Step sequences
    • WasteMartA driver’s day: jobs, evidence, sign-off, end of day.
    • ManaGEM

  5. 05Step

    Interface systems

    Turn structure into a consistent, reusable interface.

    • Design system
    • Component library
    • Screen designs
    • ManaGEMA design system GEMIS formally adopted.

  6. 06Step

    Development handoff

    Make sure what is built matches what was designed.

    • Prototype
    • Specifications
    • Review notes
    • ManaGEMPrototype functionally reviewed.
    • WasteMart
    • GEMIS
